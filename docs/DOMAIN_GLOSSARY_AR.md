# قاموس المجال المحاسبي

هذا القاموس يحدد معنى المفهوم قبل ربطه بأي جدول. الاسم البرمجي لا يغير المعنى المحاسبي.

## 1. الهيكل التنظيمي

| المفهوم | المعنى | ملاحظة تصميمية |
|---|---|---|
| Organization | مساحة العميل أو المجموعة داخل النظام | ليست بالضرورة كيانًا قانونيًا مستقلًا |
| Legal Entity | كيان قانوني يملك دفاتر وتقارير وعملة وتقويمًا | مستوى أساسي للملكية والتقارير القانونية |
| Business Unit | وحدة تشغيلية أو إدارية | قد تشمل أكثر من كيان حسب assignments |
| Branch | موقع أو فرع تشغيلي | قد يكون بلا كيان في بيانات انتقالية |
| Department | وحدة مسؤولية تنظيمية | قد تكون مركزية بلا فرع |
| Cost Center | بُعد لقياس التكلفة والمسؤولية | لا يعني بالضرورة حسابًا محاسبيًا |
| Profit Center | بُعد لقياس الإيراد والتكلفة والربحية | يستخدم في التحليل الإداري |
| Project | نشاط أو عقد أو مشروع زمني | يمكن أن يحمل ميزانية وحركات |

## 2. الزمن والعملة

| المفهوم | المعنى |
|---|---|
| Fiscal Calendar | تقويم الفترات المالية لمنظمة أو كيان |
| Fiscal Period | فترة قابلة للإقفال، مثل شهر أو ربع أو سنة |
| Currency | عملة الحركة أو العملة الوظيفية أو عملة التقرير |
| Exchange Rate | سعر تحويل مرتبط بتاريخ ونوع، مثل spot أو closing |
| Effective Dating | اختيار السجل الصالح في تاريخ الحركة بدل استخدام أحدث سجل فقط |

## 3. الحسابات والتقارير المالية

| المفهوم | المعنى |
|---|---|
| Group Account | حساب موحد على مستوى المجموعة |
| Entity Account | حساب محلي تابع لكيان قانوني |
| Account Mapping | ربط الحساب المحلي بحساب المجموعة |
| Mapping Version | نسخة مؤرخة من قواعد الربط؛ لا تعاد كتابة النسخ التاريخية |
| Account Hierarchy | شجرة عرض وتجميع للتقارير، وقد تختلف عن شجرة التسجيل |
| Normal Balance | طبيعة الرصيد: مدين أو دائن |
| Journal Entry | قيد محاسبي له رأس وأسطر مدين ودائن |
| Journal Entry Line | السطر الذي يحمل الحساب والأبعاد والمبلغ |

قاعدة القيد المزدوج هي:

```text
Total Debits = Total Credits
```

ولا يمثل جدول `Expense` وحده دفتر أستاذ عامًا.

## 4. الحركات التشغيلية

| المفهوم | المعنى |
|---|---|
| Expense | حدث مصروف تشغيلي مع تاريخ ومبلغ وأبعاد مصدر |
| Invoice | مستند AP أو AR برأس وتفاصيل وضريبة وإجمالي |
| Invoice Line | تفصيل يحدد الحساب والأبعاد والمبلغ والضريبة |
| Payment | حركة دفع أو تحصيل نقدي |
| Payment Allocation | توزيع دفعة على فاتورة أو أكثر |
| Supplier / Customer | طرف تجاري للمشتريات أو المبيعات |
| Tax Code / Tax Rate | تعريف الضريبة ومعدلها الفعال زمنيًا |
| Encumbrance | التزام أو حجز من الميزانية لم يتحول إلى actual |

الربح لا يساوي التدفق النقدي دائمًا؛ لذلك تبقى الفواتير والدفعات والقيود مفاهيم منفصلة.

## 5. الميزانية والتخطيط

| المفهوم | المعنى |
|---|---|
| Budget Plan | دورة أو مستند خطة مالية |
| Budget Version | نسخة أصلية أو معدلة أو forecast من الخطة |
| Budget Line | أصغر قيمة مالية محفوظة في الميزانية عند grain الأبعاد |
| Scenario | حالة تخطيطية مثل base أو best case |
| Scenario Version | لقطة قابلة للمراجعة والقفل من السيناريو |
| Scenario Blend | قاعدة مزج actuals والتخطيط حسب الفترة والأولوية |
| Planning Driver | متغير يفسر أو يقود قيمة التخطيط |
| Calculation Rule | قاعدة حساب معتمدة؛ ينفذها محرك Django الآمن |
| Calculation Run | سجل تشغيل للقواعد والمدخلات والنتيجة |
| Planning Fact | نتيجة تشغيل التخطيط عند grain مالي صريح، وليست actual |

الفرق الحاسم:

```text
BudgetLine   = إدخال أو خطة معتمدة
PlanningFact = نتيجة حساب قابلة لإعادة البناء
Expense      = حركة فعلية تشغيلية
JournalLine  = حركة دفتر أستاذ رسمية
```

## 6. التحكم والتقارير والتوحيد

| المفهوم | المعنى |
|---|---|
| Workflow | تعريف خطوات الاعتماد وتسلسلها |
| Approval Request | طلب اعتماد لكائن تشغيلي |
| Planning Submission | تسليم نطاق تخطيطي للمراجعة |
| Role / User Scope | صلاحية ونطاق مستخدم؛ لا يفرضهما dbt |
| Report Template | تعريف تقرير layout وscope وأعمدة |
| Report Run Snapshot | artifact ثابت لنتيجة تقرير في وقت محدد |
| Consolidation Group | مجموعة كيانات للتقارير الموحدة |
| Elimination Entry | قيد استبعاد ناتج عن التوحيد |
| Intercompany Match | نتيجة مطابقة حركة بين كيانين |
| Translation Adjustment | أثر تحويل العملات في التوحيد |

تعريف التقرير ليس fact ماليًا. ونتيجة التوحيد لا تصبح fact منشورًا قبل نجاح دورة التوحيد وقواعد المطابقة والاستبعاد.

## 7. مصطلحات تقنية مشتركة

| المصطلح | المعنى في هذا المشروع |
|---|---|
| Source of Truth | الطبقة التي تملك إنشاء وتعديل المفهوم |
| Grain | معنى الصف الواحد في نموذج dbt |
| Operational Model | جدول Django قابل للتحرير أو مرتبط بسير عمل |
| Analytical Model | جدول أو view dbt قابل لإعادة البناء |
| Staging | تنظيف أنواع وأسماء وتمرير source metadata دون business aggregation |
| Intermediate | ربط والتحقق واختيار السجل الفعال |
| Fact | حدث أو قيمة مالية عند grain معلن |
| Dimension | بُعد وصفي يستخدم للتصفية والتجميع |
| Mart | نموذج جاهز لاستهلاك التقرير أو Cube |
| Lineage | مفاتيح ومعلومات تربط النتيجة بمصدرها وتشغيلها |
